# Fort Automation Profile Integration

Source reviewed: **FORT AUTOMATION PROFILE**, 24 pages, supplied 22 September 2026.

## New capability evidence added to the website

- 2D and 3D CAD modelling
- Manufacturing drafting with GD&T
- Conceptual design and drafting
- Legacy 2D-to-3D conversion
- Progressive-tool design and detailing
- Special-purpose-machine design and development
- Checking fixtures and gauges
- CMM part-holding fixtures (not a claim of CMM inspection capability)
- Application-specific and welding fixtures
- Reverse-engineering project routes
- Press tools and dies
- Metrology lab workstations

These capabilities are presented as **partner-supported, requirement-specific project routes**. The website does not state that every capability is performed directly by Quantamorph or available for every RFQ.

## Portfolio imagery used

Four images were extracted from the supplied profile and attributed in the website section:

- Special-purpose machine example - profile page 8
- Checking fixture - profile page 14
- Application fixture CAD example - profile page 19
- Reverse-engineering component example - profile page 21

The extraction script records the page and embedded-image indexes and creates optimized AVIF and WebP assets without modifying the source PDF.

## Information deliberately not published

- Fort Automation's founding date, mission statements and generic quality claims are not presented as Quantamorph facts.
- Fort's phone numbers, email address and location are not used as Quantamorph contact information.
- The customer list on page 24 is not published because those organisations are not evidenced as Quantamorph customers and reuse permission has not been established.
- The phrase "CMM part-holding fixture" is not converted into a claim that Quantamorph or Fort operates a CMM inspection service.
- No specific performance, cycle-time, safety-compliance, tolerance or validation claims are inferred from portfolio photographs.
